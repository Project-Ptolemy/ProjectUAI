First time connecting?
  1. Install Node.js 18 or newer on this computer.
  2. In Roblox, open UAI → Cowork → Download bridge files.
  3. Open a terminal in your executor workspace and run node UAI/bridge/start.txt.
  4. Open the printed link. Paste the same token into Roblox’s Cowork panel and turn Enabled on.

Keep Roblox and the terminal open while you work.
