# Desktop keyboard controls

These shortcuts apply while the **UAI Bridge desktop window** has focus.
The Cowork browser tab keeps its browser and chat shortcuts.

| Shortcut | Destination or action |
| --- | --- |
| Ctrl+1 | Workspace |
| Ctrl+2 | Connections |
| Ctrl+3 | Updates |
| Ctrl+4 | Settings |
| Ctrl+5 | Tunnels |
| Tab / Shift+Tab | Move between available controls |
| Space or Enter | Activate the focused control |
| Alt+F4 | Close the desktop window and stop its owned bridge |

Page shortcuts use the same navigation as the sidebar and start at the page's
heading. Automatic status refresh and resizing preserve the current page's
scroll position. Disabled controls stay disabled during startup, shutdown and
other operations that own their resources.

Minimize retains the desktop app in the taskbar. Closing exits after owned
processes stop; it does not hide the application in a tray. A second launch
restores the existing window.
