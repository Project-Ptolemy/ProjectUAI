# Maintain the public website

Edit `index.html`, `style.css`, and `script.js` at the repository root. The
matching files under `docs/` are publishing copies generated by
`node tools/build_site.js`; do not edit them independently.

Tool names, descriptions, groups and counts come from the current native client
bundle. Review client/source and website changes first, rebuild the native
bundle, inspect it, then build the site and inspect the generated catalog and
publishing copies. The site build rejects stale client source.

```powershell
luajit tools/bundle.lua --native
node tools/build_site.js
# Inspect generated output before verification.
node tools/build_site.js --check
python test/site_static.py
node test/site_browser.js
```

Browser checks require an external Playwright installation identified by
`PLAYWRIGHT_MODULE`. They run against a local server and do not verify remote
release downloads or Roblox rendering. `UAI_SCREENSHOTS` optionally retains
responsive screenshots. Keep dependencies and browser downloads outside this
repository.

The catalog accepts `toolQuery`, `toolGroup`, and `toolRisk` URL parameters.
Typing replaces the current history entry; copying a filter link includes only
those catalog parameters and targets `#tools`. Unknown categories or risk values
are ignored. Clear removes the catalog parameters while preserving unrelated
URL state. Search also works with `/` to focus and Escape to clear its text.

The Share section, copy buttons and search toolbar appear only when JavaScript
initializes them. Without JavaScript, all tools remain available through native
disclosures. Clipboard denial selects the visible text for manual copying.
Keep these fallback paths and the keyboard navigation when changing layouts.

Public onboarding should match the actual client: provider setup is opt-in,
Project UAI Free and HCNSEC are separate library entries, and a hidden SDK window
still requires the device's credential-storage setup or unlock.

The public 3.8.0 release link uses `releases/tag/v3.8.0`. Its Windows download is
`releases/download/v3.8.0/UAI-Bridge-3.8.0-win-x64.exe`; Android retains the
published 3.7.1 companion asset. Update the release link, download URL, visible
version and browser expectation together as part of publication. Keep published
downloads independent of future source-tree candidates. UI LIB is independently
versioned at 1.6.0.
