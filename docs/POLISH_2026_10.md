# October 2026 polish and verification

Project UAI 3.8.0 continues the recovered polish session. The final requested
scope is at least **400 substantive changed files**, with a majority under
`src/` and `ui-lib/src/`. A changed file is not automatically a separate feature:
implementation, regression coverage, examples and generated outputs support the
user-visible changes documented in the [changelog](../CHANGELOG.md).

## Change ledger

The release ledger contains **432 changed files**: **246 existing files**
and **186 new files**, excluding ignored local artifacts. There are **219
paths under `src/` and `ui-lib/src/`** (50.7%): 191 native source-tree paths and
28 library source paths. Two native paths are generated embedded guides;
excluding them leaves **217 authored source files out of all 432 changes
(50.2%)**, still a source majority. Of the 432 paths, 11 are generated artifacts
or website mirrors, leaving 421 authored/supporting files overall.
**No companion files changed.** These counts describe files, not independent
features or a substitute for reviewing the changes.

The per-file sizes below use additions/deletions against baseline commit
`72a07adf699c` for existing files and the complete line count for each new file.
This includes this ledger itself. New-file counts were recalculated before
committing the release.
